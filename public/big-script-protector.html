Big Script Protector

Protects Lua / Luau scripts of any size through the rbx.lol obfuscator by splitting them into pieces and stitching the result back together.

Changes are saved in this browser. Piece sizes are tried from the first one down until the server accepts them; if the server reports its limit, the page jumps straight below it.

Blocked by CORS?

This page talks to the API straight from your browser. If the rbx.lol server does not allow requests from other websites, the browser blocks them and you will see "Could not reach …". Fixes:

1. Open this file from the same site (not possible for most people), or 2. run a tiny proxy that adds the CORS headers and put its URL in Settings → API endpoint. Example Cloudflare Worker:

export default {
  async fetch(req) {
    const cors = {
      'access-control-allow-origin': '*',
      'access-control-allow-methods': 'POST, OPTIONS',
      'access-control-allow-headers': 'content-type',
    };
    if (req.method === 'OPTIONS') return new Response(null, { headers: cors });
    const r = await fetch('https://rbx.lol/api/protect', {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: await req.text(),
    });
    return new Response(r.body, { status: r.status, headers: { ...cors, 'content-type': 'application/json' } });
  },
};

Tip: replace '*' with your own site's origin so strangers can't use your proxy.

Everything runs in your browser; your script is only sent to the endpoint above. Always test the protected result in your executor.
